# Art Elvin B. Miranda — Portfolio

Personal portfolio website of **Art Elvin B. Miranda**, a 4th-year Bachelor of Science in Computer Science student at **Angeles University Foundation**.

## Live Website

- **Portfolio:** https://artelvin-bm.github.io/aebm-portfolio/

## Design Direction

This redesign focuses on a custom creative identity: expressive typography, editorial-inspired composition, and purposeful interaction design.

The site is intentionally personal and playful while staying professional and easy to navigate.

## Sections

- Intro / Hero
- About
- Projects (Puchokoy, Sentiment Analysis for Product Reviews, Rental Listing App, UnliConnections, Prime Number Toolkit)
- Skills
- Contact
- Minimal footer

## Interaction Features

- Scroll progress indicator
- Animated but subtle hero sequence
- Active-section navigation highlighting
- Mobile menu with proper open/close, outside-click close, and `Esc` handling
- Scroll-triggered reveal animations using `IntersectionObserver`
- Desktop-only pointer-reactive hero accent element
- Reduced-motion support for all key animations

## Tech Stack

- `index.html`
- `style.css`
- `script.js`

No framework, build system, or external dependency is required.

## Local Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/artelvin-bm/aebm-portfolio.git
   ```
2. Open `index.html` in your browser.

## Accessibility and UX Notes

- Semantic sectioning and clear heading hierarchy
- Keyboard-accessible navigation and controls
- Visible focus states
- Responsive layout for desktop, tablet, and mobile
- Preserves content readability even if JavaScript motion is unavailable
