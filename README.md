## Projects

### Sentiment Analysis for Product Reviews

A web-based sentiment analysis system that classifies product reviews using a lexicon-based approach.

**Technologies:** PHP, MySQL, JavaScript, AJAX, Bootstrap

### Rental Listing App

A Flutter mobile application for browsing rental listings with filtering, favorites, persistent local storage, and light and dark mode support.

**Technologies:** Flutter, Dart, SharedPreferences

### Puchokoy

A personal Discord bot project built around a conversational child-like personality with message history and AI-generated responses.

**Technologies:** Python, Discord.py, AI

### UnliConnections

A web-based word association game inspired by Connections, developed as a programming project focused on interactive gameplay.

**Technologies:** Flask, Python, JavaScript

### Prime Number Toolkit

A command-line toolkit for working with prime numbers using multiple approaches, including checking, listing, factoring, counting, and sieve-based generation.

**Technologies:** NASM, x86 Assembly, Linux
